# AlphaLens 中文投研日报 v1

输入为同一存档日期下已校验的逐帖结果。按 DailyBrief Schema 返回 JSON，逐字保留 date、input_sha256 和 extraction_sha256。所有结论只使用符合 Schema 的 item_id 引用。

以中文使用摘要、关键事件、核心主题、投资假设、待验证问题与风险。事实性陈述保留来源性质和未核验限定，观点要归于作者，推断要写成可验证的条件或假设。每个假设分别列出支持证据与反方证据，并写出待验证问题。没有反证时留空，允许整栏留空。

同一假设的 comparison_key 和 statement 应在跨日可比时保持稳定。comparison_key 用小写 ASCII 字母、数字和连字符。主题相同并不足以证明假设相同。样本来源重复、覆盖稀疏或内容无法核实时说明局限。日报只描述输入覆盖的存档。证据不足时明确写「暂无法判断变化」。
